공지 모음 수집기 설치

공지는 PC 크롬의 확장 프로그램이 12시간마다 모읍니다. PC 한 대에 한 번만 설치하면 됩니다.

확장 프로그램 받기 (zip)
  1. 받은 zip 파일의 압축을 풀고, 나온 notice-extension 폴더를 지우지 않을 곳(예: 문서 폴더)에 둡니다.
  2. 크롬 주소창에 chrome://extensions 를 입력합니다.
  3. 오른쪽 위 개발자 모드를 켭니다.
  4. 압축해제된 확장 프로그램을 로드합니다를 누르고 notice-extension 폴더를 고릅니다.
  5. 주소창 오른쪽 퍼즐 모양에서 공지 모음 수집기를 고정하면 아이콘이 보입니다.
  6. 아이콘을 눌러 이 웹사이트와 같은 이메일, 비밀번호로 로그인합니다.
  7. 공지를 모을 게시판을 크롬으로 열고, 아이콘의 이 페이지를 게시판으로 추가를 누른 뒤 공지 제목 하나를 누르고 저장합니다.

새 버전이 나오면 zip을 다시 받아 같은 폴더에 덮어쓰고, chrome://extensions 에서 수집기의 새로고침(↻)을 누릅니다.
창을 모두 닫아도 수집하려면 크롬 설정 chrome://settings/system 에서 "Google Chrome이 닫혀도 백그라운드 앱 계속 실행"을 켭니다.
